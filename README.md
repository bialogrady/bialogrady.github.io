# Białogrądy — nasze miejsce

Gotowa, statyczna strona HTML/CSS/JS do wrzucenia na GitHub Pages.

## Pliki

- `index.html` — cała treść strony i układ sekcji.
- `style.css` — wygląd, kolory, responsywność i ilustracja krajobrazu wykonana w CSS.
- `script.js` — menu mobilne.

## Co warto zmienić przed publikacją

1. W `index.html` zamień przykładowe wpisy w sekcji **Ogłoszenia** i **Kronika** na własne treści.
2. Wyszukaj w pliku adres `kontakt.bialogrady@gmail.com` i zastąp go własnym adresem, jeśli wybierzesz inny.
3. Przy każdym materiale historycznym wpisz dokładne źródło, datę, numer gazety/dokumentu oraz link do oryginału, jeśli istnieje.
4. Zdjęcia i skany możesz później dodawać jako osobne pliki w folderze `img/`, a następnie w HTML użyć np. `<img src="img/skan-1830.jpg" alt="Opis skanu">`.

## Publikacja na GitHub Pages

1. Utwórz nowe repozytorium na GitHubie.
2. Wgraj do niego pliki `index.html`, `style.css`, `script.js` oraz ten `README.md`.
3. Wejdź w **Settings → Pages**.
4. W sekcji publikacji wybierz **Deploy from a branch**, następnie gałąź `main` i folder `/root`.
5. Zapisz ustawienia. Po chwili GitHub pokaże adres strony.

Strona jest nieoficjalna i nie udaje strony urzędu, gminy ani sołectwa. Informacje urzędowe warto linkować do właściwych oficjalnych serwisów.

## Informacje użyte w pierwszej wersji

Opis lokalizacji oparto na publicznych informacjach: Białogrądy znajdują się w gminie Grajewo, powiecie grajewskim i województwie podlaskim. Wspomnienie o dolinie Biebrzy jest kontekstem regionalnym, a nie deklaracją, że każdy fragment miejscowości znajduje się w granicach Biebrzańskiego Parku Narodowego.
